# Guía de Arquitectura de Internacionalización (i18n) - Go PAPAYA

Esta guía describe la arquitectura, configuración, convenciones y flujos para el sistema de internacionalización profesional de la plataforma **Go PAPAYA**.

---

## 1. Tecnología y Enfoque

* **Librería**: Transloco (`@jsverse/transloco` v8.4.0) optimizado para **Angular 19 Standalone**.
* **Idiomas Soportados**:
  * 🇪🇸 **Español (`es`)** (Idioma por defecto y Fallback principal)
  * 🇺🇸 **Inglés (`en`)**
* **Patrón de Arquitectura**:
  * Carga asíncrona (Lazy-loading) de diccionarios JSON ubicados en `src/assets/i18n/`.
  * Cambio dinámico reactivo en tiempo de ejecución sin recarga completa de la página (preservando estado en memoria, temporizadores, Web Bluetooth BLE y sesiones de juego).
  * Desacoplamiento total entre lógica de negocio y presentación visual.

---

## 2. Jerarquía de Detección y Persistencia

El servicio `LanguageService` (`src/app/core/services/language.service.ts`) inicializa el idioma siguiendo este orden de precedencia:

```text
1. Parámetro de URL (?lang=es | ?lang=en)
   ↓
2. Preferencia previa guardada en localStorage ('gopapaya_lang')
   ↓
3. Idioma detectado en el navegador (navigator.language)
   ↓
4. Fallback por defecto ('es')
```

### Sincronización con el DOM y URLs
* Cuando el usuario cambia de idioma, se actualiza automáticamente el atributo `<html lang="es|en">`.
* Se sincroniza el query parameter `?lang=xx` mediante navegación interna de Angular Router (`replaceUrl: true, queryParamsHandling: 'merge'`).
* El valor se almacena en `localStorage` con la clave `'gopapaya_lang'`.

## 3. SEO Internacional, GEO/AEO y Metadatos

El servicio `I18nSeoService` (`src/app/core/services/i18n-seo.service.ts`) actualiza de forma reactiva en cada cambio de ruta e idioma:

* `<title>` localizado dinámicamente con sufijo `| Go PAPAYA`.
* `<meta name="description">` y `<meta name="keywords">`.
* Metadatos para redes sociales:
  * Open Graph: `og:title`, `og:description`, `og:locale` (`es_ES` / `en_US`), `og:locale:alternate`, `og:site_name`, `og:type`.
  * Twitter Cards: `twitter:card`, `twitter:title`, `twitter:description`.
* Etiquetas de indexabilidad multilingüe:
  * `<link rel="canonical" href="https://gopapaya.com/path?lang=xx">`
  * `<link rel="alternate" hreflang="es" href="https://gopapaya.com/path?lang=es">`
  * `<link rel="alternate" hreflang="en" href="https://gopapaya.com/path?lang=en">`
  * `<link rel="alternate" hreflang="x-default" href="https://gopapaya.com/path?lang=es">`
* **Datos Estructurados Schema.org (JSON-LD)**: Inyección dinámica de grafo `@graph` con entidades `Organization` y `SoftwareApplication` para motores de búsqueda semántica y motores de respuesta con IA (GEO/AEO: Perplexity, ChatGPT, Gemini, Copilot).

## 4. Componente Selector de Idioma Accesible

* Ubicación: `src/app/shared/components/language-selector/language-selector.component.ts`.
* Selector: `<app-language-selector></app-language-selector>`.
* Integrado en la barra superior de todos los layouts:
  * Header para **Super Administrador**
  * Header superior para **Administrador** (y menú flotante)
  * Header para **Visualizador (Viewer)**
  * Pantalla de autenticación (**Login**) en la esquina superior derecha
* **Accesibilidad (WCAG)**:
  * Navegación por teclado (soporte para `Escape`, `ArrowDown`, `Enter`).
  * Atributos ARIA: `aria-haspopup="listbox"`, `aria-expanded`, `aria-selected`, `aria-current="true"`, `aria-label`.
  * Estados de foco visibles (`focus:ring-2 focus:ring-neon-yellow`).

## 6. Cómo Usar Traducciones en Componentes

### En Plantillas HTML (Pipes):
```html
<p>{{ 'home.welcome' | transloco }}</p>
<button [attr.aria-label]="'common.save' | transloco">{{ 'common.save' | transloco }}</button>
```

### En Clases TypeScript (Servicio):
```typescript
import { inject } from '@angular/core';
import { TranslocoService } from '@jsverse/transloco';

export class MiComponente {
  private transloco = inject(TranslocoService);

  mostrarMensaje(): void {
    const texto = this.transloco.translate('common.success');
    console.log(texto);
  }
}
```

## 7. Cómo Agregar un Nuevo Idioma (Ej. Portugués `pt`)

1. Crear el nuevo archivo de catálogo: `src/assets/i18n/pt.json`.
2. Registrar el idioma en `src/app/app.config.ts`:
   ```typescript
   availableLangs: ['es', 'en', 'pt']
   ```
3. Agregar la opción en `LanguageService` (`src/app/core/services/language.service.ts`):
   ```typescript
   { code: 'pt', name: 'Português', flag: '🇧🇷', label: 'PT' }
   ```
4. Registrar el locale correspondiente de Angular si se requieren formateadores de fechas:
   ```typescript
   import localePt from '@angular/common/locales/pt';
   registerLocaleData(localePt);
   ```

---

## 8. Manejo de Datos Provenientes de API

* **Textos de UI**: Traducidos siempre mediante Transloco.
* **Datos Dinámicos de Backend**: Si la API devuelve estructuras multi-idioma (ej. `{ name_es: "...", name_en: "..." }` o `{ translations: { es: "...", en: "..." } }`), los componentes deben consumir el campo correspondiente al idioma activo consultando `languageService.getActiveLanguage()`.
